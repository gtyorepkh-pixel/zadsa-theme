# Zad Pro — ثيم خدمات منزلية احترافي

مبني على كور ثيم **ميمو** (إطار الخيارات `_inc/_admin` ومنطق القوائم)، بتصميم جديد كلياً (RTL، موبايل أولاً).

## ما الجديد
- **CPT الخدمات `zad_service`** (الرابط `/services/`) مع تصنيفين: `service_cat` (الأقسام + أيقونة) و`service_area` (المدن/الأحياء، تولّد صفحات «خدماتنا في ...»).
- حقول كل خدمة: سعر يبدأ من، ضمان، مدة، سرعة استجابة، تقييم، مميزات، خطوات تنفيذ، أسئلة شائعة، معرض صور، فيديو، أرقام تواصل مخصصة، خدمات ذات صلة، شارة، «خدمة مميزة».
- **نموذج طلب سعر** (AJAX + بديل بدون JS): يخزّن كل طلب في **طلبات العملاء** (`zad_lead`) بحالة قابلة للتغيير، يرسل بريداً، ويعرض زر تأكيد واتساب. حماية: honeypot + حد 5 طلبات/ساعة لكل IP.
- **Schema.org** تلقائي: LocalBusiness، Service (+Offer, AggregateRating)، FAQPage، BreadcrumbList.
- شريط اتصال/واتساب/عرض سعر ثابت على الجوال، وأزرار عائمة على الشاشات الكبيرة.
- الرئيسية: واجهة + نموذج، أرقام، أقسام، خدمات مميزة، لماذا نحن، آلية العمل، مناطق الخدمة، آراء، أسئلة شائعة، مدونة، دعوة ختامية.
- ألوان الهوية من **إعدادات القالب ← الهوية والألوان**.

## التركيب
1. ارفع المجلد كثيم وفعّله (يُعاد ضبط الروابط تلقائياً). إن ظهرت 404 على `/services/` اذهب إلى الإعدادات ← الروابط الدائمة ← حفظ.
2. أضف أقساماً ومدناً ثم خدماتك، وعيّن القوائم (القائمة العلوية/الفوتر).
3. أعد استخدام بيانات الثيم القديم: كل مفاتيح الخيارات القديمة (`_memo_theme_options`) ما زالت تعمل.

## ملاحظات
- المحتوى القديم (المقالات) محفوظ بتنسيق متوافق.
- نموذج الطلب بلا nonce عمداً ليعمل مع الكاش.

## تركيب القالب على موقع قائم (وضع التبنّي)
- القالب **لا يغيّر أي رابط موجود**. يطبّق التصميم الجديد على أنواع المحتوى (CPT) الموجودة بحسب رابط كل نوع:
  - خدمات: `pest-control` و`cleaning` و`moving` ← تصميم الخدمة الكامل.
  - أسئلة: `faq` ← تصميم السؤال.
  - مقالات: `sections` و`guide` (والمقالات العادية) ← تصميم المقال.
- تعديل الروابط المطابقة: إعدادات القالب ← الهوية والألوان.
- بعد التفعيل: الأدوات ← **تبنّي المحتوى الحالي** ← اكتب مدنك ← تنفيذ.
- محتوى الصفحات القديمة (عنوان/وصف/صورة/فيديو/أرقام التواصل المخزّنة في حقول القالب القديم) يُقرأ تلقائياً.
- لا تستخدم «بيانات تجريبية Zad» على موقع فعلي.
