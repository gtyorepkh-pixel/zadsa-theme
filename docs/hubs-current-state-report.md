# صفحات الأقسام (Hubs) — الوضع الحالي (قبل أي تعديل) — الثيم 3.28.1

لم يُعدَّل أي سلوك في الموقع. أُضيفت أداة قراءة فقط: **الأدوات ← تقرير صفحات الأقسام (Hubs)** تُخرج من قاعدة بيانات موقعك الحقيقي: مصدر كل H1/عنوان، وقائمة الصفحات التي ستصير «قسم» بروابطها وعناوينها، وأي تطابق عناوين.

## الملفات الحالية
| الملف | ما يفعله الآن |
|---|---|
| `archive-zad_service.php` | أرشيف أي نوع خدمة «متبنّى» (cleaning / pest_control …) ← يستدعي `template-parts/hub-service.php`؛ أرشيف `/services/` الأصلي ← `service-archive.php`. |
| `template-parts/hub-service.php` | دليل شامل: H1 + مقدمة + «فهرس الخدمات» + (نظرة عامة body) + «اختر حسب حالتك» + مقارنة أسعار/مدة/ضمان + مناطق التغطية + أدلة + 6 أسئلة شائعة + أرقام (أقل سعر). |
| `taxonomy-service_cat.php` و`taxonomy-service_area.php` | كلاهما يستدعي `service-archive.php` (شبكة كروت خدمات + بحث + فلتر أقسام + نموذج طلب + CTA). H1 للمدينة = «خدماتنا في {الاسم}»، وللقسم = اسم التصنيف. |
| taxonomies `cleaning-sections` / `pest_sections` | لا قالب خاص ← `archive.php` العام. |
| إعدادات «صفحات الأقسام (Hubs)» `zad_hubs` | صفوف: slug (رابط النوع) · headline · lead · body · decide · tips · cta. تُقرأ بـ `zad_hub_opt($pt)` وتُطابَق بـ slug النوع أو مفتاحه. |
| أداة «محتوى الأرشيف (زاد)» (`inc/zad-suite.php`) | تربط **صفحة (مسودة)** بأرشيف نوع/تصنيف/كاتب: تُعرض كاملة (`the_content`) تحت الـ H1 داخل `.zad-archive-content`، وتُستعمل أيضاً لتغيير **عنوان الأرشيف** (`zad_ac_title`) وعنوان/وصف السيو (`zad_ac_seo`). |
| `single-zad_service.php` | تصميم الخدمة لكل صفحة خدمة، وإن كان لها أبناء تُضاف كتلة `zad_children_html`؛ والـ Schema يحوّلها لـ CollectionPage + ItemList مع بقاء Service (`inc/zad-schema.php` ~121). لا يوجد حقل «نوع الصفحة». |

## لماذا `/pest-control/` عنوانها «خدمات التنظيف في السعودية»؟
ترتيب مصادر الـ H1 في `hub-service.php` (الكود فعلاً):
1. `zad_hubs` ← صف slug يطابق `pest-control` ← **العنوان الرئيسي**.
2. وإلا: **عنوان الصفحة المربوطة** بالنوع في «محتوى الأرشيف» (`zad_archive_content_mappings['pest_control']`) — الدالة `zad_ac_title`.
3. وإلا: اسم نوع المحتوى (`labels->name`).
والـ `<title>`: عنوان SEO المخصّص في «محتوى الأرشيف» ← Yoast للصفحة المربوطة ← عنوان الصفحة المربوطة + اسم الموقع ← افتراضي القالب `zad_type_default`.

الكود نفسه لا يضع «التنظيف» في المكافحة؛ لازم يكون المصدر **بيانات**: (أ) صف zad_hubs بعنوان التنظيف (نسخ/لصق)، أو (ب) نفس الصفحة مربوطة بالنوعين، أو (ج) عنوان SEO مخصّص منسوخ. التقرير على الموقع الحقيقي يسمّي أيّاً منها بالضبط ويحذّر من التطابق (جرّبته على موقع الاختبار بمحاكاة (ب)+(أ) فأظهر المصدر والتطابق). **لا أستطيع تحديده من هنا لأن البيانات في قاعدتك**؛ أرسل التقرير.

## المعروف مسبقاً مما يحتاج الموقع
- لا يوجد في القالب حقل «نوع الصفحة: تلقائي/خدمة/قسم».
- لا يوجد `hub-simple.php`؛ الـ Hub الحالي يعرض أسعاراً وضماناً ومقارنة وأسئلة (ما تمنعه المواصفات).
- أرشيف المدينة (`service_area`) وأقسام الخدمات (`service_cat`) كلاهما شبكة خدمات عامة بنموذج طلب وليسا بتصميم القسم المطلوب.
- Schema الأرشيف الحالي: CollectionPage + ItemList (+ Breadcrumb) على الأرشيفات، لكن **صفحات الخدمات الهرمية التي لها أبناء** تحتفظ بـ Service (+CollectionPage). المواصفات تريد بلا Service للأقسام ← يتطلب تعديل `zad-schema.php` لهذه الحالة (مطلوب صراحةً في طلبك).
- القاعدة المقترحة لصفحة هرمية = «قسم»: **بلا مدينة** (حسب `zad_city_resolve`: حقلها، آباؤها، الرابط) و**تحتها صفحات منشورة لها مدينة محددة**. من لها مدينة تبقى خدمة. محاذير: مدينة غير موجودة في `zad_city_map` تُحتسب «بلا مدينة»؛ لذلك التقرير يعرض فئة «مشتبه» (أبناء أسماؤهم مدن غير معروفة) كي لا يتحوّل شيء بالخطأ قبل إضافتها من «مدن الخدمات».
